# Publicación en GitHub Pages

Sube exactamente esta estructura al repositorio, conservando la carpeta `assets`:

```text
index.html
assets/
  app.js
  styles.css
```

Después, en GitHub, entra en **Settings → Pages**, selecciona **Deploy from a branch**, elige la rama `main` y la carpeta `/ (root)`, y guarda. Espera unos minutos y abre la URL que GitHub muestre en esa misma sección.

No cambies los nombres ni muevas los archivos fuera de `assets`.
